## 動作確認について

本章はSPRESENSEの基本動作確認を目的としています。<br>
サンプルスケッチの詳細な説明は含んでいません。<br>

スケッチの意図や注意点については、<br>
ソースコード内のコメントを参照してください。<br>

必要に応じて、別途ドキュメントを追加予定です。<br>

現在はUSBシリアル通信でPCと接続する構成としています。<br>

シリアルのボーレートについては115200を使用していますが、カメラを使用するときは921600にしていますので注意してください。

LTE通信については現在動作確認中です。<br>
確認が取れ次第、本ドキュメントを更新します。<br>

##  各プログラムの位置づけ

### LED_Blink_simple
本体のみで確認できるLチカ  

### Serial_countup_simple
USBシリアル疎通確認用。  
ログ出力確認（L1）。

### Spresense_SerialLedController / GPIOController
GPIOの動作確認用
1文字コマンドによる制御確認。  

### GNSS統合スケッチ
GNSS測位・Fix判定・レスポンス出力。  
LINEからの問い合わせも可能ですが、屋内ではGNSSの取得に時間がかかります。

### Spresense_CamJpeg_Usb...
CameraでJPEG取得し、USB経由でバイナリ転送。  
大容量データ転送検証。
Node-REDと組み合わせることでLINEから画像の取得も可能です。
