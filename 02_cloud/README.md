# 02 Cloud（ローカル検証サーバー）

## ゴール

ローカルPCをサーバーと仮定し、  
LINE Webhookとデバイス間の動作確認を行います。

本章はクラウド本番構成ではなく、  
**動作検証を目的とした構成**です。

---

## 現在の構成（検証段階）

- デバイス：SPRESENSE  
- デバイス接続：USBシリアル通信  
- サーバー：ローカルPC  
- LINE連携：Messaging API（Webhook）  

### 構成イメージ


SPRESENSE
↓↑（USBシリアル）
ローカルPC（仮サーバー）
↓↑（Webhook）
LINE


---

## 事前準備

ローカルPCに以下をインストールしておくと動作確認がスムーズです。

- Node-RED
- ngrok

シリアル通信をハードウェアとして扱うため、  
ローカル環境での実行を前提としています。

flows.jsonをNode-REDで読み込んで使用してください。

### 参考記事

Node-REDおよびngrokのインストール手順はこちら：

https://qiita.com/shinfrom/items/e5ecf1ac68f5f0b7118f

※ 本記事はWindows環境での検証内容です。  
（少し古いので注意してください）

Mac環境の場合は適宜読み替えて使用してください。

---

## 役割

ローカルPCは以下の役割を担います。

1. LINEからのWebhook受信  
2. デバイスとのシリアル通信  
3. デバイス応答をLINEへ返信  

---

## 動作確認内容

- LINEからメッセージを送信できる  
- ローカルサーバーがWebhookを受信できる  
- サーバーがシリアル経由でデバイスへ送信できる  
- デバイスの応答をLINEへ返却できる
